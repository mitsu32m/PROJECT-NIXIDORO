## 状態の定義
- **CONFIRMED**: ユーザーが製品方針として採用。具体型番まで確定した意味ではない
- **PROPOSED**: 調査結果から有力な候補。発注確定ではない
- **TO_VERIFY**: 実測、メーカー仕様書、試作確認が必要
- **REJECTED**: 既に不採用の案
- **VERIFIED**: 実測条件・記録を伴い動作確認済み。現時点で該当なし

発注区分: **A=先行発注候補 (試作の汎用部品)** / **B=条件を確認してから発注** / **C=最終設計を待つ（予算期限との衝突時は評価基板等で代替）**。

## USB-C・本体OFF・保護回路（2026-11-14）
- 本体背面USB-C 5VシンクでBQ25185へ充電入力。候補 GCT USB4105-GF-A (USB2.0データ線あり、シールド/固定脚付き)。https://www.digikey.jp/en/products/detail/gct/USB4105-GF-A/11198441
- CC1/CC2各5.1kΩ Rdで5Vシンクを構成し、CCで通知された供給可能電流を超えないようBQ25185の入力制限を設定。コネクタ・ESD/サージ・VBUS保護とUSBデータ経路は詳細設計待ち。
- **充電回路は主電源OFFでも動作させる**方向。主電源OFFは高電圧電源OFF（Enable）+ MCU低消費電力化/低圧負荷切断を中心に検討。安全なメンテナンスの電池切り離しは別途。
- TPS22918DBVRは候補ロードスイッチ（1〜5.5V、2A、SOT-23-6、shutdown typ 0.5µA）。https://www.ti.com/product/TPS22918 。**eFuseではなく過電流保護は非搭載**。切る場所と必要電流、OFF時の逆給電を検証。XIAOのGPIOで電源を制御する際の起動/保持ロジックにも注意。
- XIAOのUSB-Cを試作書き込みに使用。本体USB-CとXIAO USB VBUSの単純並列はしない。最終単一ポート化は回路・FW設計が必要なため未決。
- 180–200V HVレールのEN制御と**高耐圧ブリーダ/放電経路**、エンクロージャの感電保護は別系統で設計・確認する（ロードスイッチでHV遮断は不可）。

## ニキシー・ネオン球の固定方式（2026-11-14）
- **IN-12B ×2: PCBに個別ソケットレセプタクルを実装する方式を第一候補**。交換できること、PETGのガイドとPCB側支持を分離し、高電圧端子に触れないこと。IN-12Bのピン径約1.02mm、SK-136/1mm用接点が参照される。接点の具体型番・適合範囲・ピッチと孔径は実物測定後に選定。参考 https://www.tube-tester.com/sites/nixie/data/in-12b.htm
- **ネオン球12灯: 専用PCBとPETGガイドで位置決めし、電気接続ははんだ付け**。φ4mmガラス管を圧入せず振動対策とリードの応力逃しを付ける。RS PRO 655-9413は公表長さ37mm（リード含むか要実物確認）、0.25mA、直列制限抵抗必須。参考 https://jp.rs-online.com/web/p/indicator-lamps/6559413 。10個入り×2袋で予備8個、MonotaRO約¥2,416税込/送料別。
- 電極・配線の覆い、十分な沿面/空間距離、残留電圧の放電確認と安全な交換手順が必要。PETG外装だけでは安全評価を代用できない。
- **購入はまだ確定しない**。実管のピン位置とガラス径・ソケット試験片、筐体CAD寸法を先に整合させる。

## 筐体・OLED窓の素材選定 (2026-11-14)
- **第一候補: Bambu Lab PETG HF ブラック**で球体・操作台を造形。A1公式資料でPETGは推奨、ASA/ABSは基本非推奨。Bambu公式: https://jp.store.bambulab.com/products/petg-hf 。1kg約¥2,400–3,400の販売例、スプール有無・店舗で変動。使用前の乾燥が必要。
- **OLED窓: スモークPMMA 2mm**。具体的な比較候補としてアクリサンデーEX530(19%透過率)を追加。https://item.rakuten.co.jp/acrysunday/1024669/ 。19%は表示時の輝度低下が大きい可能性があり、もっと透過率の高い板と**実機比較してから確定**。
- OLED基板寸法・表示エリア・スモーク板の厚みをCADに反映。スモーク窓を接着固定する前に、電池、スイッチ、基板を交換できる分解構造を設計。
- マット外観は材料だけで保証されない。造形方向、積層ピッチ、積層痕、研磨/塗装での溝の潰れ、ネオン球の熱/電気絶縁を確認。
- PETGは3Dプリント材料として適切な候補だが、**高電圧回路を覆うだけで安全な絶縁・耐火仕様を満たすとは限らない**。HV基板の離隔と指が触れないカバーを別途設計。

## 通知音・アンプ選定メモ（2026-11-14）
- 第一候補: TPA2005D1、8Ω/0.5–1W級の直径約28mmスピーカー（スピーカー型番は未選定）。TI https://www.ti.com/product/TPA2005D1
- アンプVDD=2.5–5.5V。8Ωで最大1.4Wは5V/THD 10%条件、**3.3V時の出力は小さいが通知用途には十分な可能性**がある。スピーカーの許容入力以下になるようにソフトとハードで音量制限。
- シャットダウン時消費0.5µA typ、通常約2.8mA @3.6V。通知時間以外は確実にshutdownを使用する。
- XIAO RP2350のPWMをアナログ入力アンプに接続するには適切なフィルタ/結合/音量設計が必要。差動アンプの出力をGNDへ接続しない。ポップ音と高電圧スイッチング由来のノイズを評価。
- スピーカーの音色は筐体に依存するため最終型番は音響試験後に決定。

## MCU選定メモ（2026-11-14）
- **XIAO RP2350を試作から完成品まで使う第一候補**とし、STM32U073K8は省電力化・さらなる小型化の代替候補。いずれも未発注。
- Seeed公式: https://wiki.seeedstudio.com/xiao_rp2350_arduino/ / ST公式: https://www.st.com/ja/microcontrollers-microprocessors/stm32u073k8.html
- 端子概算13本：HV5524シリアル4、OLED+RTC I²C2、ACTION/NEXT2、押し込み式エンコーダ3、音1、高電圧電源Enable1。HV5524 POLなど固定レベルで処理する信号の妥当性は別途確認。
- XIAO RP2350の最大19 GPIOは裏面パッドも含むため、モジュール搭載方法と実際の端子配線で使える本数を確認する。
- ボードとしてのスリープ電流（LED、周辺回路、電源レール）はMCU単体仕様とは異なる。実測前に電池寿命改善効果を断定しない。
- 専用BQ25185 charger とXIAO側の既存電池充電機能を併用する構成は不可または要厳密設計。XIAOの電源接続、外部3.3V供給、USB接続時の電源逆流を資料で確認する。

## RTC選定メモ (2026-11-14)
- 第一候補: Micro Crystal RV-3028-C7 32.768kHz 1ppm-TA-QA。メーカー https://www.microcrystal.com/en/products/real-time-clock-rtc-modules/rv-3028-c7/ 、DigiKey https://www.digikey.jp/ja/products/detail/micro-crystal-ag/RV-3028-C7-32-768KHZ-1PPM-TA-QA/10499248
- 25°Cで±1ppm（約2.6秒/30日相当）。45nA @3V typ、1.1–5.5V、I²C、アラーム、VBACKUP自動切替。

- 極小パッケージなのでリフロー、フットプリント確認、検査方法が必要。最終発注前に在庫再確認。

## 3.3V / 5Vレギュレータ選定メモ (2026-11-14)

**結論 [PROPOSED]: SYS→TPS63031→3.3V、SYS→TPS61023→5Vを第一候補とする。型番の電圧範囲は整合するが、出力容量・効率・起動動作は未検証であり発注区分Cを維持する。**

### 電源接続と整合性
```text
USB-C 5V → BQ25185 IN
保護付き1S Li-ion ↔ BQ25185 BAT
BQ25185 SYS ┬→ TPS63031 → 3.3V → MCU / OLED / RTC
            └→ TPS61023 → 5V ┬→ HV5524 VDD / 74AHCT125
                             └→ MAX668系の入力 → HV → 表示管
```
- BQ25185: 4.2V終止の通常1S Li-ionを前提とする。USB給電時のSYSは通常4.5V（精度±2%）、電池単独時はBATから内部FETを介して供給されるため電池電圧より低下する。入力不足時はSYSも低下し得る。**SYSを固定5Vや固定3.8Vと扱わない**。初期評価範囲はSYS約3.0–4.6Vとするが、3.0Vは保証された下限ではない。低電圧停止閾値・配線/FET降下・過渡値を含む設計範囲は別途確定。[BQ25185 Rev.B §7–8](https://www.ti.com/lit/ds/symlink/bq25185.pdf)
- HV5524: VDD推奨4.5–5.5V、VIH最小0.8×VDD。4.5V±2%のSYS直結では下限余裕がなく電池時も不足する。安定5Vと3.3→5V変換を使う。5V時のVIHは4.0Vなので3.3V GPIO直結は不可。HVOUT推奨上限220VとVDDは別の定格である。[HV5524 §1](https://ww1.microchip.com/downloads/aemDocuments/documents/APID/ProductDocuments/DataSheets/HV5524-32-Channel-Serial-to-Parallel-Converter-Data-Sheet-DS20006850.pdf)
- MAX668: 通常VCC=3–28V、VCC/LDOを接続する構成では2.7–5.5V。5V入力は範囲内。高電圧出力はVCCへ接続せずnon-bootstrapped構成とする。VCC/LDO接続は参照回路との照合後に決定する。単セル直結もIC条件上は検討可能だが、参照回路の5V入力・FETゲート駆動・トランス電流条件を変えるため今回は継続案にしない。MAX669の1.8V起動仕様をMAX668に流用しない。[MAX668/MAX669 Rev.3 §Electrical Characteristics / Low-Voltage Non-Bootstrapped Operation](https://www.analog.com/media/en/technical-documentation/data-sheets/MAX668-MAX669.pdf)
- MAX668内部LDOは外部3.3V/5Vレールの代用にしない。MCU/OLED/RTCの各基板の入力端子、XIAOのUSB接続時の給電経路、アンプの給電先は別途確認する。
- 既存の `docs/architecture.md` のSYS→HV直結矢印は代替方式を含む旧案。今回のMAX668参照回路案では上図の**5V経由**を前提とする。

### 容量見積もりの方法 [TO_VERIFY]
- 5V出力電流は `I5 = PHV / (5 × ηHV) + I_HV5524 + I_level + I_other5V`。PHVには管電力だけでなく電流制限抵抗等の消費も含める。MAX668の無スイッチング時IC電流だけをHV電源の入力電流と見なさない。
- **計算例に限る**: HV=170V・総負荷10mAならPHV=1.70W、ηHV=75%仮定でMAX668系の5V入力は約0.45A。さらにη5=90%、SYS=3.0Vならこの分だけでSYS入力約0.84A。両効率・負荷は未測定であり実消費の予測値ではない。
- SYS総入力は `P5/(VSYS×η5) + P3.3/(VSYS×η3.3)`。起動時のHVコンデンサ充電、音声ピーク、USB使用中の充電余力も加える。BQ25185の入力電流制限・熱制限・BAT経路、電池保護とホルダの定格を突き合わせる。
