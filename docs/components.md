## 状態の定義
- **CONFIRMED**: ユーザーが製品方針として採用。具体型番まで確定した意味ではない
- **PROPOSED**: 調査結果から有力な候補。発注確定ではない
- **TO_VERIFY**: 実測、メーカー仕様書、試作確認が必要
- **REJECTED**: 既に不採用の案
- **VERIFIED**: 実測条件・記録を伴い動作確認済み。現時点で該当なし

発注区分: **A=先行発注候補 (試作の汎用部品)** / **B=条件を確認してから発注** / **C=最終設計を待つ（予算期限との衝突時は評価基板等で代替）**。

- **XIAO RP2350を試作から完成品まで使う第一候補**とし、STM32U073K8は省電力化・さらなる小型化の代替候補。いずれも未発注。

- 専用BQ25185 charger とXIAO側の既存電池充電機能を併用する構成は不可または要厳密設計。XIAOの電源接続、外部3.3V供給、USB接続時の電源逆流を資料で確認する。

## 1Sバッテリー検討メモ（2026-11-14）
- 第一候補: Keeppower P2150R **protected** 21700 5000mAh。メーカー: https://www.keeppower.com/product/p2150r-keeppower-21700-5000mah-protected-li-ion-rechargeable-battery-max-15a/ 。公称3.6/3.7V、約18Wh、最大φ21.6×74.5mm、70g、過充電/過放電/過電流/短絡保護あり。
- 国内候補: ユタカパワーバッテリー掲載のP2150R 2本¥3,380（2026-11-14確認、価格・在庫変動）。https://item.rakuten.co.jp/yutaka-battery/c/0000000004/
- **重要:** 保護回路付き製品でも、充電温度を測るNTC付きとは限らない。BQ25185のTS/MR端子へ温度情報を渡す方法を必ず設計・試験する。
- BQ25185は最大1A充電のため、5000mAhを0から理想的に1Aで充電するだけでも5時間以上。CC/CV・充電中使用・熱制限によりさらに延びる。実充電時間は未測定。
- 21700電池ホルダ・固定方法の寸法は**保護回路付きの全長約75mm**に合わせる。生セル用70mmホルダと混同しない。極性逆挿入、接点脱落、ユーザー露出、ケース内部熱、交換時残留HVを評価。
- 選定競合: (a)保護付き21700 + 外付け接触式NTC、(b)保護/NTC内蔵の認証済1S電池パック。後者はコネクタと保守性次第で有利。P2150Rの放電最大15Aは本機には過剰で安全性能を示す根拠にはならない。

## 高電圧電源の設計メモ (2026-11-14)
- ユーザー意向: kohacraftの昇圧回路を自作・統合する方向で検討。
- 元記事は**MAX668とトランス結合SEPIC**を採用し、1:10トランス、FB抵抗、FREQ/CS+の設定抵抗に言及。前のFlyback案とは方式が違うため設計比較が必要。
- フィードバック抵抗を変えると目標電圧を変更できる。ただし実際に希望電圧で安定動作できるか、最大負荷、出力保護、過渡動作は別途設計/試験が必要。
- **調整可能≠通電中に可変抵抗を回してよい**。安全性のため固定抵抗・停止中の設計変更等を優先検討する。
- 最終の負荷/レール電圧/絶縁・故障時保護は実管測定と指導者による確認後に確定。

## 3.3V / 5Vレギュレータ選定メモ (2026-11-14)

**結論 [PROPOSED]: SYS→TPS63031→3.3V、SYS→TPS61023→5Vを第一候補とする。型番の電圧範囲は整合するが、出力容量・効率・起動動作は未検証であり発注区分Cを維持する。**

### 電源接続と整合性
```text
USB-C 5V → BQ25185 IN
保護付き1S Li-ion ↔ BQ25185 BAT
BQ25185 SYS ┬→ TPS63031 → 3.3V → MCU / OLED / RTC
            └→ TPS61023 → 5V ┬→ HV5524 VDD / 74AHCT125
                             └→ MAX668系の入力 → HV → 表示管
```
- BQ25185: 4.2V終止の通常1S Li-ionを前提とする。USB給電時のSYSは通常4.5V（精度±2%）、電池単独時はBATから内部FETを介して供給されるため電池電圧より低下する。入力不足時はSYSも低下し得る。**SYSを固定5Vや固定3.8Vと扱わない**。初期評価範囲はSYS約3.0–4.6Vとするが、3.0Vは保証された下限ではない。低電圧停止閾値・配線/FET降下・過渡値を含む設計範囲は別途確定。[BQ25185 Rev.B §7–8](https://www.ti.com/lit/ds/symlink/bq25185.pdf)
- HV5524: VDD推奨4.5–5.5V、VIH最小0.8×VDD。4.5V±2%のSYS直結では下限余裕がなく電池時も不足する。安定5Vと3.3→5V変換を使う。5V時のVIHは4.0Vなので3.3V GPIO直結は不可。HVOUT推奨上限220VとVDDは別の定格である。[HV5524 §1](https://ww1.microchip.com/downloads/aemDocuments/documents/APID/ProductDocuments/DataSheets/HV5524-32-Channel-Serial-to-Parallel-Converter-Data-Sheet-DS20006850.pdf)
- MAX668: 通常VCC=3–28V、VCC/LDOを接続する構成では2.7–5.5V。5V入力は範囲内。高電圧出力はVCCへ接続せずnon-bootstrapped構成とする。VCC/LDO接続は参照回路との照合後に決定する。単セル直結もIC条件上は検討可能だが、参照回路の5V入力・FETゲート駆動・トランス電流条件を変えるため今回は継続案にしない。MAX669の1.8V起動仕様をMAX668に流用しない。[MAX668/MAX669 Rev.3 §Electrical Characteristics / Low-Voltage Non-Bootstrapped Operation](https://www.analog.com/media/en/technical-documentation/data-sheets/MAX668-MAX669.pdf)
- MAX668内部LDOは外部3.3V/5Vレールの代用にしない。MCU/OLED/RTCの各基板の入力端子、XIAOのUSB接続時の給電経路、アンプの給電先は別途確認する。
- 既存の `docs/architecture.md` のSYS→HV直結矢印は代替方式を含む旧案。今回のMAX668参照回路案では上図の**5V経由**を前提とする。

### 容量見積もりの方法 [TO_VERIFY]
- 5V出力電流は `I5 = PHV / (5 × ηHV) + I_HV5524 + I_level + I_other5V`。PHVには管電力だけでなく電流制限抵抗等の消費も含める。MAX668の無スイッチング時IC電流だけをHV電源の入力電流と見なさない。
- **計算例に限る**: HV=170V・総負荷10mAならPHV=1.70W、ηHV=75%仮定でMAX668系の5V入力は約0.45A。さらにη5=90%、SYS=3.0Vならこの分だけでSYS入力約0.84A。両効率・負荷は未測定であり実消費の予測値ではない。
- SYS総入力は `P5/(VSYS×η5) + P3.3/(VSYS×η3.3)`。起動時のHVコンデンサ充電、音声ピーク、USB使用中の充電余力も加える。BQ25185の入力電流制限・熱制限・BAT経路、電池保護とホルダの定格を突き合わせる。
