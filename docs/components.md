## 状態の定義
- **CONFIRMED**: ユーザーが製品方針として採用。具体型番まで確定した意味ではない
- **PROPOSED**: 調査結果から有力な候補。発注確定ではない
- **TO_VERIFY**: 実測、メーカー仕様書、試作確認が必要
- **REJECTED**: 既に不採用の案
- **VERIFIED**: 実測条件・記録を伴い動作確認済み。現時点で該当なし

発注区分: **A=先行発注候補 (試作の汎用部品)** / **B=条件を確認してから発注** / **C=最終設計を待つ（予算期限との衝突時は評価基板等で代替）**。

## 現時点で避ける購入
- 12本まとめた**IN-6**：方式変更でREJECTED。
- 既に選んだ型番と異なるネオン球を「NE-2」表記だけで大量購入。
- 動作未検証の最終HVトランス・MOSFET・細部抵抗一式を完成設計向けと決め打ち購入。
- 付帯保護や温度監視を確認していない裸Li-ionセル。
- 未確認の規格の管ソケットやレーザー/スモーク窓を大量購入。

## 購入判断の優先順位
1. **期限内に予算化でき、後で使い回せる試作用部品**（MCU、OLED、操作部、LED等）
2. **長納期で意匠・回路を左右する部品**（数字ニキシー、ネオン球、特殊ドライバ）
3. **型番の適合検証が要る電源/充電部品**（期限前に評価基板や既製試験モジュールを検討）
4. **最終仕様がまだ変わる基板や筐体**（発注期限直前に無理に凍結しない）
