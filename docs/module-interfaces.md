# モジュール間インターフェース仕様 — Draft v0.1
Updated: 2026-11-14 (JST)
Status: PROPOSED / TO_VERIFY

> 本文は**試作→完成品への部品・基板再利用を優先する構成案**。正式な回路図、コネクタ型番、PCB実装仕様、購入承認ではない。電流値やピン番号は設計・実測前に固定しない。

## 1. 目的と判断基準
- 約¥50,000の予算内で、**電源モジュールを完成品にそのまま転用**する。
- 高電圧・電池・制御領域を安全に切り分け、異常時に各モジュールが安全側へ遷移する。
- PCBはJLCPCBを第一候補とし、可能なら初回基板群を一度に発注する。PCB製造枚数と発注回数は区別する。
- 通常の作業は基板単位で試験し、合格後に組み合わせる。試作PCBを無条件で完成品へ転用せず、電気・温度・筐体・安全の合格判定を行う。

## 2. モジュール分割：3論理モジュール（暫定）

| ID | 主要機能と部品候補 | 想定位置 | 試作→完成品 |
|---|---|---|---|
| PWR | USB-C、BQ25185、保護付き1S Li-ion+NTC、TPS63031 3.3V、TPS61023 5V、入力保護 | 台座、充電端子付近 | **同じPCBを再利用する第一候補** |
| HV | MAX668、個別仕様が確認できたトランス、MOSFET、整流、FB、独立OVP、bleeder、スナバ、EN | 電池から距離を取れる内部領域 | **同じPCBを再利用する第一候補** |
| CTRL / DISP | XIAO RP2350（試作）、HV5524、74AHCT125、IN-12B×2、ネオン×12、OLED/RTC/操作・音声インターフェース | 表示球体と操作台 | 筐体制約で**制御PCB＋表示PCBに分割可** |

- 「3論理モジュール」は「物理基板が必ず3枚」という意味ではない。CTRL/DISPは実装・配線の都合で2枚になる可能性あり。
- HV5524とニキシー管を同じ基板とするか、表示位置に合わせて分割するかは筐体CADと絶縁・配線長から決定。
- 低圧UI試験はブレッドボード等で実施可能、専用PCBを当然には発注しない。

## 3. 電気インターフェース（信号定義のみ確定する方針）

| 接続 | 信号候補 | 名目電圧 / 目的 | 必須条件 / 未確定 |
|---|---|---|---|
| 外部→PWR | USB_VBUS, USB_GND, CC1, CC2 | USB Type-C 5Vシンク | 電流広告とBQ25185入力制限、ESD/サージ、データ線利用は設計待ち |
| 電池→PWR | BAT+, BAT−, TS_NTC | 1S保護付きLi-ion | コネクタ極性、逆挿入、セル密着NTC、充電中の温度監視 |
| PWR→HV | +5V_HV, GND_PWR | 5V入力 | 電圧許容範囲、定常/起動/故障時最大電流、線幅、リターン経路を後で確定 |
| CTRL→HV | HV_EN | ロジック信号 | **未駆動、MCUリセット、CTRL断、コネクタ抜去で昇圧OFF**。極性、レベル、プル抵抗の選定待ち |
| HV→CTRL/DISP | HV_OUT, HV_RETURN | 暫定200–205V DC | **低圧コネクタから物理分離**、誤挿入防止、耐圧・沿面/空間距離、接触防止、残留電圧 |
| PWR→CTRL | +5V_LOGIC, GND_LOGIC | XIAOへの5V候補と5Vロジック | **XIAO内蔵USB/充電ICとの競合・逆流禁止**。Seeed 3V3出力への直接給電は禁止（メーカー別途確認がない限り） |
| PWR→CTRL | +3V3_PERIPH, GND_LOGIC | OLED、RTC等の3.3V | MCU基板由来3.3Vとの**電源競合を禁止**。I²Cレベル/プルアップ配置確認 |
| PWR→CTRL | CHG_STATUS, POWER_GOOD (optional) | 電源状態の通知 | BQ25185出力論理、レベル、プルアップ、実用性を検討 |
| CTRL→DISP | SHIFT_DATA, SHIFT_CLK, LE, BL (POL固定候補) | 3.3→5V変換したHV5524制御 | 74AHCT125 / 5V未投入時の逆給電防止、起動時全OFF |
| CTRL→UI | I2C_SCL/SDA, ACTION, NEXT_L/R, ENC_A/B/SW, AUDIO | 低電圧の表示と操作 | 全GPIO数、GPIO割当、入力保護、ケーブル長は後で確認 |

### HV_RETURN / GNDについて
- HV電源が非絶縁型であればHV_RETURNは内部で低圧側GNDと共通となり得る。それでも**高電圧出力側コネクタと低圧コネクタを分離**し、各電流ループの帰路をレイアウトで管理する。
- 「分離」は電気的な絶縁を保証する言葉ではない。絶縁/非絶縁の実構成は回路方式とトランス資料に従って明記する。

## 4. パワーの境界条件（暫定）
- PWR: USB-C 5V入力→BQ25185 SYS（USB接続時と電池時で変動）→5V昇圧、3.3V昇降圧。
- HV: +5V_HV給電からMAX668電源。出力200–205Vは暫定評価点、通常負荷と16mA級ストレス負荷を試験する計画。200V×16mA=3.2W、効率70%仮定なら入力5V×0.914A。
- **PWRの5Vブースト能力、USB入力上限、熱、電池放電電流、入出力の突入電流がこの条件を満たすか未証明**。起動時、充電+表示時を含めて実測/設計で検証。
- HV5524の推奨最大HVOUT 220Vのため、出力リップル、起動オーバーシュート、負荷解放、FB故障を含む独立OVPが必要。215Vは停止閾値の仮候補であって確定値ではない。

## 4A. PWR→HV 5V負荷計算・コネクタ第一次絞り込み（2026-11-14）

**全て暫定値で、設計保証・発注確定ではない。** 200V出力、MAX668電力段効率70%、TPS61023効率85%の保守的な仮定。

| HV電流 | HV出力電力 | MAX668 5V入力電流 = Pout/(0.70×5V) |
|---|---:|---:|
| 4mA | 0.8W | 0.229A |
| 8mA | 1.6W | 0.457A |
| 12mA | 2.4W | 0.686A |
| 16mA | 3.2W | 0.914A |

- 上表はMAX668のみ。仮に5V系のロジック等0.5Wを追加すると、16mA時の5V合計は約5.07W=1.014A。TPS61023効率85%仮定ならSYS入力約5.97W。SYS 3.3Vで**約1.81A**、SYS 4.5Vで**約1.33A**。USB電流とSYS電流は異なる。その他の3.3V負荷と各IC損失、過渡は未算入。
- TPS61023公式は3.6V→5V/1.5A時94%の参考効率、スイッチ valley current limit 3.7A typと規定。3.7Aを「保証出力電流」と誤認しない。データシートで3V台低電池の電流制限最小値・熱を確認。https://www.ti.com/product/TPS61023
- BQ25185はUSB入力制限100/500/1100mAのいずれか。**USB入力500mAで最大HV負荷+充電を同時に賄えるとは考えない**。SYS負荷優先→充電電流低下→電池補完が起こり得る。1100mA設定もUSB-CソースのCC電流広告や規格適合・追加充電余力を自動で保証するわけではない。https://www.ti.com/lit/ds/symlink/bq25185.pdf
- **PWR→HV低電圧専用候補:** JST XH 3極 2.5mmピッチ、定格3A AC/DC (AWG22使用時)・250V AC/DC（メーカーシリーズ値）。信号例 Pin1=+5V_HV、Pin2=GND、Pin3=HV_EN。ただし**ピン配列と部品型番は暫定**、ワイヤ径・圧着工具・ハウジング・header、耐久/温度、筐体の干渉を確認。https://www.jst-mfg.com/product/index.php?series=277
- **JST XHをHV出力用として採用した意味ではない。** 高電圧側は物理形状の異なる専用品を選び、接続事故防止、残留電荷、絶縁距離、装着中の接触防止を満たす。『250V定格』だけでHV出力用安全性を保証しない。
- HV_ENはHV基板側でハードウェアOFFをデフォルト（プルダウン/必要な論理極性）とする。5V/HVの立上り、切断・再接続、MCUの未起動/不意のリセット時もOFFを確認。
- **次のGo/No-Go:** MAX668の通常・軽負荷・最大負荷効率、TPS61023の最低電池電圧における入力電流・インダクタピーク・接合温度、BQ25185の入力制限/電池補完と充電熱を数値モデルおよびベンチ試験で検証する。

## 5. 停止・故障時の挙動（設計要求）
| 状態 | 必要な挙動 | どう確認するか |
|---|---|---|
| 電源未投入/MCUリセット | HV_EN=OFF、HV5524全出力OFF | 起動シーケンスと端子レベル実測 |
| CTRLコネクタ未接続 | HV起動禁止 | HV基板単独で5V印加して確認 |
| USB脱着/電池切替 | 意図しないHV起動・表示暴走なし | 電源切替試験 |
| PWR 5V過負荷 | 規定の制限/停止、発熱異常なし | ダミー負荷・熱試験 |
| HV無負荷/FB異常 | 独立OVPが動作、HV5524許容上限を超えない | 教員の安全レビュー下で条件付き試験 |
| 通常OFF | 高電圧昇圧を停止し、残留電荷を規定時間内に放電 | 放電曲線を実測、許容電圧と時間は安全レビュー後決定 |
| 電池温度超過 | 充電制限/停止（BQ25185 + NTC） | 温度模擬・実セル温度の試験 |

## 6. コネクタと基板の物理インターフェース
- コネクタ**型番・ピン番号・ピッチは未決定**。まず必要な電圧定格、電流、誤挿入防止、繰返し挿抜、メンテナンス時の露出対策を計算する。
- **HV_OUTと低圧5V/GND/ENを同じ一般コネクタへ混載しない**。高電圧側のコネクタが露出する状態で通電・交換できない構造を検討。
- 5V電力配線とHVスイッチングループは低インピーダンス・短配線を優先。PWM制御線やI²Cから距離を取る。
- 取付穴、外形、最大高さ、部品干渉、電池の隔離、ネジの導通/絶縁、ケーブル曲げ半径をCAD設計で確定。**寸法を推測して固定しない**。
- リフロー作業と高電圧試験のため、安全な基板固定とプローブ位置を設計する。学校のリフロー設備利用は未確認。

## 7. 製造・予算の選択肢
- **案A（基準）:** PWR PCB + HV PCB + CTRL/DISP PCB（物理的に必要ならCTRL/DISPを2枚へ分割）。試作基板を合格後に完成品へ再利用。
- **案B（比較）:** PWR + HVを1枚に統合、CTRL/DISP別。製造枚数/送料を削減できる可能性がある一方、充電熱・高圧ノイズ・故障切分け・再利用性が低下。実カート価格と熱/安全の比較後に判断。
- JLCPCBの基板製造、ステンシル、送料、税、関税等、交換コネクタ、ネジ、余剰枚数を見積もる。面付けで必ず安くなるとは限らない。
- **初回発注¥40,000以下・予備¥10,000確保が目標（達成未確認）**。安全関連の部品・評価を削って達成しない。

## 8. 初回設計前のGo / No-Go
1. HVトランスの特定枝番について、メーカーのLp、飽和特性、巻線抵抗、巻線極性、温度、入手性が揃う。
2. PWRの5V出力の定常・瞬間・熱の余裕を最大HV負荷+CTRL負荷で確認する。
3. BQ25185とXIAOのUSB/電池電源の競合防止を、メーカー回路図で説明できる。
4. HV5524の耐圧、全消灯回路、独立OVP、放電経路を設計・安全レビューする。
5. MCUと表示管の取付寸法、基板外形の上限、工具・検査アクセスを3D模型で検証する。
6. JLCPCB試作を含む現実のBOMが¥50,000以内、残予算と期限が確認できる。
7. 高電圧測定は接触対策、残留電荷、電源遮断、測定器/オシロ接地の手順を教員と確認する。
