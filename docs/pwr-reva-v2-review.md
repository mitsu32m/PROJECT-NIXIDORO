# PROJECT-NIXIDORO PWR Rev.A 回路図ドラフト v2

2026-11-14。**設計検討用。PCB・ガーバー・発注用BOMではない。**

KiCad 10で `PWR_RevA.kicad_pro` を開く。単一シートのネットラベル接続図で、受動部品とMOSFETはドラフト用の箱形シンボルを使っている。シンボル内のピン番号は選定したメーカー資料に合わせた。既存Rev.Aの基準は[統合ネット仕様](https://github.com/mitsu32m/PROJECT-NIXIDORO/blob/main/docs/reva-integrated-net-spec.md)。TPS63031は含めない。

## 変更した回路

### BQ25185 /CE

U1の**/CE（4番ピン）をGNDへ直接接続**した。前版のSYSへのプルアップR8は、要求されたUSB接続時の自動充電を常時止めるため削除した。TIは/CE=LOWを充電許可、HIGHを充電停止と定義する。したがって有効なUSB入力と正常なTS/MRがある間、MCUの起動状態に依存せず充電できる。[TI BQ25185 Rev.B](https://www.ti.com/lit/ds/symlink/bq25185.pdf)

| 状態 | 想定動作・制限 |
|---|---|
| 充電器5 V、適合セルとNTCあり | /CE=LOWで自動充電。18 kΩのILIM/VSETは4.2 V・入力500 mA、1.2 kΩのISETは公称250 mA。入力電流制限、温度・熱制御、SYS負荷による充電電流低減は別途作用する。 |
| MCU停止またはCTRL未接続 | /CEはMCU信号を使わないため充電許可状態を維持。充電安全はBQとセル保護・NTCに依存する。 |
| 電池未接続、USBあり | TI資料ではBAT端子のコンデンサを充放電し、充電と完了を繰り返す。STAT2が切り替わり得る。**STATだけでセル存在を確定しない。** SYSの安定性をセル模擬器・電池なしで試験する。 |
| USBなし、セルあり | 充電は行われず、BQのBAT→SYS経路で給電。/CEはバッテリー補助給電の許否ではない。 |
| NTC断線・短絡、熱異常 | メーカーのTS/MR検出を実部品・ケーブルで検証する。TS/MRを固定抵抗で無効化しない。 |

自動充電は**USB供給能力・セル型番・NTC適合が確認されるまで試験対象の提案**であり、発注確定ではない。

### Pico 2 ADC分圧と逆給電

R10/R12/R14（上側）を100 kΩ 1%、R11/R13/R15（下側）を47 kΩ 1%、C10–C12を各1 nFの候補に変更。Q1–Q3（[Nexperia BSS84AK](https://assets.nexperia.com/documents/data-sheet/BSS84AK.pdf)）を各電源の高側に置く。Q4–Q6（[Nexperia 2N7002](https://assets.nexperia.com/documents/data-sheet/2N7002.pdf)）がP-MOSのゲートを引き下げる。P-MOSゲートは各電源へ1 MΩでプルアップするため、`ADC_SENSE_EN`がLOWまたはCTRL未接続なら原則OFF。信号にはPWR側で100 kΩのプルダウンR24を置き、J3を**9極案から10極案**に変更した。CTRLのGP17は第一候補だが、実配線・ファームは未変更。

## KiCad検証

`erc.txt`：KiCad 10 ERC **エラー0・警告0**。`PWR_RevA.net`：更新後のネットリスト。`netlist-footprint-check.txt`：主要34ピンのネット接続と、U1/U2/U3/U4/D1/J4/Q1–Q6のフットプリント内パッド番号を自動照合。KiCad CLIは制限環境でレジストリアクセスのメッセージを出したが、出力は完了した。

ERCは単一ラベル検査が初期設定で無効であり、箱形シンボルやオフ状態、素子故障、温度、USB規則、物理レイアウトを検証しない。**ERC成功を安全性・動作保証とみなさない。**

## 発注前の残課題

1. USB入力電流の運用条件を確定し、CC電流広告・PC接続・列挙有無とBQ 500 mA設定の整合を検証する。eFuseのOVLO/クランプ/突入/短絡/熱と、TVSの過渡・異常印加を実測する。
2. 保護付き21700の**実型番**とセルに密着する10 kΩ B3435 NTCを決定し、温度範囲、断線・短絡、セルなし、充電熱、密閉PETG内温度を試験する。
3. ADCスイッチのOFF漏れ・停止過渡・故障時逆給電をPico 2実機で測り、J3の10極とGP17割当をCTRL/HV資料へ反映する。必要ならハード遮断を再設計する。
4. USB4105の筐体実寸・シールド接地、U3のWSON露出パッドとリフロー工程、全コネクタの実型番・向き・圧着・電流、R/C/Lの実品番・ケース・温度特性を決める。
5. TPS61023の最低SYS・最大5 V/HV起動負荷・熱と、HV基板の独立OVP・放電・遮断・接触防止を別途検証する。
6. **税込・送料・基板費を含む実見積BOM**を作り、総額50,000円以内、予備費10,000円目標を確認する。費用のために電池温度監視や高電圧安全機能を削らない。

PCBレイアウト、ガーバー、部品発注は実施していない。試作基板の完成品再利用は段階試験後に判断する。
