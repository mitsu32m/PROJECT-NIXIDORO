## 発注方式
- **A: 試作に必要・仕様変更に強い**: MCU、OLED、操作部、エンコーダ、LED、小物。原則期限前に調達。
- **B: 外観・回路に影響する**: ネオン球、IN-12B、ドライバ、充電IC。型番・データシートを確認してから調達。
- **C: 完成回路依存**: カスタム昇圧のトランス/受動部品、最終PCB。納期が迫っても未検証定格で発注しない。予算規則が許せば評価モジュールなど検証に資する代替を優先。

### テスター購入前の判断ゲート
1. 学校・指導教員に**測定器購入が予算上認められるか**を確認。
2. 手持ち/学校貸出のDMMで必要測定が可能か確認。不要なら部品・予備費を優先。
3. 新規購入の場合、測定範囲、メーカーの定格、プローブ・リード適合、ヒューズ、保証、正規販売経路を確認。安価な無銘DMMを高電圧測定用として無条件に採用しない。
4. **170–200V DCの試験は指導者監督下**。計測器の表示最大電圧だけで安全と判断せず、接触防止、残留電荷、計測手順と定格を別途検証する。
