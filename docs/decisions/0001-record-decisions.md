# ADR-0001: 初期方針と保留事項
Date: 2026-11-14
Status: Accepted at concept level (not electrical validation)

## 決定した方向性
1. IN-6の特殊電極制御を使用せず、12個の**普通の2端子ネオン球**を採用する。
2. 2桁の数字ニキシー＋小型OLEDを併用する。
3. 本体は球体状上部と傾斜した操作台、マットブラック、枯山水状の波紋モチーフ。
4. ACTION / NEXT / 押し込みエンコーダの3入力。
5. Grace Periodと静かな表示/通知を中心思想とする。
6. USB-C充電、バッテリー駆動、充電中動作を目指す。

## 未承認/未検証
- ネオン球はILT N516とRS PRO 655-9413が候補。まだ購入/試験で確定していない。
- IN-12B、HV5524、BQ25185、STM32U073K8、RV-3028-C7は調査からの提案。
- 高電圧電源170V/20mAは仮案であり、IN-12Bの着火条件により変更の可能性。
- 安全確認とPCB検証前に通電・運用を前提とした完成回路とはしない。
