Source report: [A 00:00](https://github.com/mitsu32m/PROJECT-NIXIDORO/blob/87d007b6b303050a8909f56c170becddff92ca2b/docs/verification/2026-11-24-0000-JST-HV-002-tlv6700-ovp-divider-static-window-screen.md); TI [TLV6700 product](https://www.ti.com/product/TLV6700), [Rev.B datasheet](https://www.ti.com/lit/ds/symlink/tlv6700.pdf). Manufacturer product information checked independently 2026-11-24 JST: 400mV nominal reference, 0.5% maximum threshold accuracy at 25C and 1% over temperature, supply 1.8–18V, open-drain outputs rated 18V, typical 5.5mV hysteresis. Datasheet Rev.B timing table: 18us **typical** high-to-low propagation at VDD5V, 10mV overdrive and 10k pullup; **no specified maximum in this row**, hence no certified worst-case hard-off time.
- ASSUMED Rtop=5.415Mohm, Rbottom=10kohm each independent ±1%; threshold 0.400V ±1% proxy (not exact verified transfer of IC electrical specification). Independently recalculated: Vnom=217.000V, Vmin=210.583782V, Vmax=223.589515V. A reported 210.584/223.590V correct. Static hypothetical normal max 214.13495V exceeds low trip; 220V recommended ceiling below high trip. **ACCEPTED (arithmetic)**; **REJECTED for this particular 1% divider + 1% proxy within historical static window**. This does not reject TLV6700 as a part.
- Divider current at 220V 40.553uA, dissipated power 8.92166mW. Input bias magnitude proxy 15nA*~9.9816kohm=0.1497mV (~0.081V input referred). **CONDITIONAL**: possible double-count with specified threshold accuracy; polarity, exact comparator channel, hysteresis, TCR, bias at supply/temperature, resistor working voltage and fault behavior need the Rev.B electrical tables and real MPNs.
- **BLOCKED hardware**: no qualified Cmin, tail energy, maximum shutdown latency, latch, supply loss default-off, open divider/return fault, converter stuck-on response, safe discharge. Need joint proof Vnormal,dynamic,max < Vtrip,min and E_tail,max < 0.5*Cmin*(220² - Vtrip,max²) with nonzero margin. Here Vtrip,max already exceeds 220V, so energy inequality cannot be satisfied for positive Etail. Treat 220V as recommended maximum, not a target threshold.
