## 3. 最重要の統合判断：同じHV容量をOVP・起動・放電で共同設計

**D-013：設計評価手順として採用。部品値・安全機能の承認ではない。**

容量を大きくするOVP対策を、起動・電源・停止・セル温度と切り離して採用しない。OVPには実効容量の**最小値Cmin**、起動・蓄積エネルギー・最遅放電には**最大値Cmax**を使う。名目容量を両方に無条件使用しない。容量・電圧係数・温度・経年・ESR・リップル・定格・故障モードを実品番で結ぶ。

### 検査式

1. 通常動的最大電圧 < OVP真の最小しきい値。
2. 証拠のある最大残留注入エネルギー E_tail,max < ½ Cmin (220²−Vtrip,max²)。配線/寄生の瞬時ピークはこの集中容量モデルとは別に確認。
3. 起動余剰エネルギーの積分が ≥ ½ Cmax(Vfinal²−Vinitial²)。余剰は灯負荷・bleeder・制御・変換損失を除いた値。瞬時電流と電源電圧降下も別に満足させる。
4. 受動抵抗放電モデルでは t=Rmax Cmax ln(Vstart,max/Vrelease)。残留源・抵抗開放・配線断など単一故障も別に検討。Vreleaseと許容時間は教員等の安全レビューで定め、勝手に「安全電圧」と呼ばない。
5. bleederの通常最大損失は Vmax²/Rmin。抵抗の電力・使用電圧・直列分担・故障冗長性をBOMに含める。
