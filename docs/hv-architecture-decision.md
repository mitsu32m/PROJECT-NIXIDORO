# Rev.A HV電源方式の一次判定

確認日: 2026-11-15 JST。対象は5V入力、200～205V出力、0～16mA連続目標（205V×16mA=3.28W）。この資料は**方式の選別**であり、HV回路の完成・通電許可を意味しない。既存KiCadのHVドラフトは昇圧不能のまま保持する。

## 結論

**第一候補は、仕様書を取得できるトランスを使った5V入力フライバックの詳細設計。** MAX668を残すか別の制御ICへ替えるかは、トランス・FET・CS・スナバ・OVPを一体で検証してから決める。候補`TTRN-060S-013-T`には巻数比、一次インダクタンス、飽和電流、漏れ、絶縁、温度のメーカー仕様を確認できず、現時点では採用しない。[JLCPCB掲載](https://jlcpcb.com/partdetail/JLCPCBAssembly-TTRN_060S_013T/C9900124494)のSMD-5P表示は電気仕様の根拠にならない。

| 方式 | 16mA・205Vの一次判定 | 主な根拠と残る条件 |
|---|---|---|
| MAX668の5V→205V一段ブースト | **不成立** | 理想デューティ97.56%、MAX668は200kΩ条件の最大デューティ87/90/93%（min/typ/max）[ADI](https://www.analog.com/media/en/technical-documentation/data-sheets/MAX668-MAX669.pdf) |
| MAX668の5V→約27V→205V二段ブースト | **推奨しない** | 205Vで最大デューティの保証下限87%を使うと中間電圧は理想で26.65V以上。MAX668入力上限28Vまで1.35Vしかなく、ダイオード降下・配線・制御余裕・段間電圧公差を入れる前に余裕不足。二段目の効率と熱も増える |
| 5V入力トランス・フライバック | **詳細設計候補** | [MAX668](https://www.analog.com/media/en/technical-documentation/data-sheets/MAX668-MAX669.pdf)はフライバック用途を示す。ただし適合するトランス、発振周波数・ピーク電流・磁束、FET/整流耐圧、ループ安定性が未検証。別制御ICも比較可能 |
| 5V入力の高電圧カスコード式 | **比較候補、実績を転用できない** | [ADI AN113](https://www.analog.com/media/en/technical-documentation/application-notes/an113f.pdf)はLT1172等で5V→200Vの回路を示すが、16mA連続出力・密閉筐体の熱・保護条件を保証していない |
| 市販HVモジュール | **現候補は不適合または予算難** | [XP Power F05](https://www.xppower.com/storage/portals/0/pdfs/SF_F_Series.pdf)は12V時500V/20mA、入力低下時の定格電流は線形低減。5Vでは定格8.33mA相当で16mAに不足。F02は最大200Vで205Vに届かず、F03を約8.2Vで使う案は別の昇圧段・負荷依存電圧・独立OVP・費用の検証が必要 |

F05の5V時出力は比例関係から単純計算で約208Vだが、メーカーは軽負荷時の過電圧と負荷依存を明記する。約208Vを制御精度や安全上限として使わない。2026-11-15時点の[DigiKey Japan F05](https://www.digikey.jp/ja/products/detail/xp-power/F05/6802049)は数量1で税込¥28,837.6、在庫5個と表示。**これは不適合品の比較価格でありBOMへ採用しない。** ¥50,000総予算中の過半を占め、加えて5→12V等の回路・保護・PCB・管が必要になる可能性がある。販売条件は発注時に再確認する。

## 再現可能な電力計算

[`hardware/hv/hv-option-model.py`](../hardware/hv/hv-option-model.py)が`hv-option-model.csv`へ、200/205V、0/4/8/12/16mA、HV効率60/70/80%、5V昇圧効率80/85/90%の**90行**を出力する。効率は測定値や保証値ではない。計算式は`Pout=VHV×IHV`、`PHV,5V=Pout/ηHV`、`I5=PHV,5V/5`、`PSYS,HV=PHV,5V/η5V`。

205V/16mAの場合、ηHVが80/70/60%ならHV基板へ入る5V電力は4.10/4.686/5.467W、電流は0.820/0.937/1.093A、HV段損失は0.820/1.406/2.187W。ηHV70%・η5V85%でSYSからHVに必要な電力は5.513W（CTRLと音声の追加分を含まない）。USB 5V/500mAは理想でも2.5Wなので、この条件を**電池なしUSB単独で満たせない**。充電と同時の成立も別途実測が必要。

MAX668二段案の理想式は`D=1−Vin/Vout`。最大デューティ保証下限87%から`Vin≥205×(1−0.87)=26.65V`。28V入力上限との差は1.35V。これは電力変換損失をゼロと仮定した**必要条件**で、成立の証明ではない。さらに二段の効率が仮に各85%なら合成72.25%、3.28W出力に対して5Vから4.54Wが必要で、追加の段の銅損・制御電力を含まない。

フライバックの方式比較に限れば、理想CCM式`Vout/Vin≈(Ns/Np)D/(1−D)`。これは巻数比選定の**初期感度**に過ぎず、DCM、整流降下、漏れサージ、磁化電流、起動状態には適用できない。実トランス仕様のないまま巻数比やMOSFET・RCS・スナバを回路図に確定しない。

## 次の設計ゲート

1. **磁性部品:** メーカー型番と一次資料でLpの公差、Np:Ns、Isat/磁束密度、漏れ、DCR、絶縁、使用周波数、温度上昇、実フットプリントと調達性を取得。得られなければトランス変更または別方式。
2. **電力段:** 5V最低値・16mA連続・ゼロ負荷・起動時のIpk、MOS VDSサージ、ダイオード逆耐圧、CS min/typ/max、コンデンサ実効容量と温度を計算し、メーカー定格内に入ることを示す。
3. **独立保護:** 最高通常出力、OVPしきい値の全公差、[HV5524推奨上限220V](https://ww1.microchip.com/downloads/aemDocuments/documents/APID/ProductDocuments/DataSheets/HV5524-32-Channel-Serial-to-Parallel-Converter-Data-Sheet-DS20006850.pdf)の関係を確認。MCU停止/5V断/コネクタ断でもハード停止し、残留電荷を定めた電圧・時間まで放電する回路を設計。接触可能な電圧と時間は試験管理者と事前に定義。
4. **システム:** 低電池・USBのみ・充電中・OLED/音声同時の電源余裕と、TPS61023・セル・トランスの密閉PETG内温度を評価。初回¥40,000、総額¥50,000の実見積を作り、予備費を維持。

## 「教員の安全レビュー」の意味

この語はプロジェクトの前提条件にある**試験前の第三者確認**を指し、法律上の資格や製品認証を意味しない。指導教員など試験を監督する責任者に、回路図・OVP/停止/放電の故障解析、PCBの触れ防止と沿面/空間距離、治具・電流制限・測定器の定格、停止後の残留電圧確認、緊急停止と試験場所を提示して、試験手順を確認してもらう。その方を特定できない場合は、同等に高電圧試験を監督できる責任者を決めるまで高電圧を印加しない。レビュー後も製品の安全認証や電気的安全性を保証するものではない。
