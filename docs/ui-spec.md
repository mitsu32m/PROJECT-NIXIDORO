# UI仕様 — 検討版 v0.1

## 3入力
- ACTION: もっとも頻繁な可逆操作/提示された通常遷移
- NEXT: 早期フェーズ終了（形状が異なる瞬間スイッチ）
- Encoder: 回転で設定、押して選択や残り時間確認

## 状態と基本動作 [PROPOSED]
| 状態 | ACTION | NEXT | Encoder |
|---|---|---|---|
| IDLE | 前回ポモドーロ開始 | - | 回してモード選択 |
| WORK | 一時停止 | 早期休憩へ（Undo付き） | 押すと残り分数数秒表示 |
| PAUSE | 再開 | - | 設定/セッション取消への導線 |
| WORK_GRACE | 休憩へ | 休憩へ | 詳細確認 |
| BREAK | （一時停止か無操作か未決） | 早期終了 | 残り時間確認 |
| BREAK_END | 次のWORK開始 | - | 詳細確認 |
| SETTINGS | 決定/戻る等要設計 | - | 回転選択/押す決定 |

## 表示
- ネオン球: WORK中は12→1灯へ段階的に減る静的な残量表示
- 数字ニキシー: 主にユーザー要求時の残り分表示（秒は表示しない方針）
- OLED: 設定・モード・一時的な状態説明。作業中は基本消灯
- 終了通知: 視覚の静的変化 → 必要なら穏やかな音
- 休憩終了後のWORK自動開始はしない

## 2026-11-14 ハード接続ドラフト
- ACTION: GPIO GP8、N.O.接点をGNDへ落とす案。
- NEXT: NKK M-N18S1W `(ON)-OFF-(ON)` の中央COMをGND、両投端子をGP6/GP7に割当。
- Encoder: Alps Alpine EC11E15244G1は**30クリック・15パルス**で押込スイッチあり。GP9/10/11を使用。クリック=1エッジと仮定しない。
- OLED: I2C (GP20/GP21)でRTCと共有。OLEDの電源OFF時逆給電が未解決なので、実装前に電源ドメインまたはI2C分離を選ぶ。
- AUDIO: GP12 PWM、TPA2005D1を使うならGP19をSHUTDOWNへ（LOW=停止）。アンプ出力はBTLでGND禁止。省略して圧電ブザーも比較。
- 詳細: [CTRL UI/OLED/AUDIO接続ドラフト](ctrl-ui-audio-schematic.md)。
